## Круги на форме

| Требование | Реализация |
| --- | --- |
| Класс CCircle с координатами и постоянным радиусом | `part_1/main.py`, `CCircle` |
| Собственный контейнер с закрытым хранилищем | `CircleStorage.__circles`, `add`, `__iter__`, `__len__` |
| Создание при нажатии мыши | `PaintArea.mousePressEvent`, ЛКМ по свободной области |
| Отрисовка всех объектов при Paint | `PaintArea.paintEvent` перебирает контейнер и вызывает `circle.draw` |
| Обработка изменения размера | `resizeEvent`, Qt повторно рисует видимую область, объекты сохраняются |
| Множественное выделение | Ctrl + ЛКМ, признак хранится в каждом круге |
| Обычное выделение и снятие | ЛКМ выбирает один круг; Ctrl переключает его состояние |
| Попадание в пересекающиеся объекты | По умолчанию верхний; `SELECT_ALL_ON_HIT` переключает на все |
| Удаление всех выделенных по Del | `keyPressEvent`, `CircleStorage.remove_selected` |
| Попадание и рисование внутри объекта | `CCircle.contains_point`, `CCircle.draw`; координаты не выдаются форме |

Контейнер внутри использует список Python, а снаружи ведёт себя как перебираемая
коллекция: основной программе не нужно знать ни имя, ни устройство хранилища.

## MVC

| Требование | Реализация |
| --- | --- |
| Три целых числа от 0 до 100 | `part_2/main.py`, `NumberModel` |
| По три элемента редактирования на число | `NumberRow`: `IntegerLineEdit`, `QSpinBox`, `QSlider` |
| Ограничение A <= B <= C | `set_a`, `set_b`, `set_c` |
| Разрешающее поведение A и C | Модель перестраивает соседние значения, сохраняя введённую границу |
| Ограничивающее поведение B | Ближайшее значение в интервале [A, C] |
| Проверки и пересчёты в модели | Представление вызывает только числовые методы модели |
| Модель работает с числами | Числовые сеттеры проверяют тип; текст разбирается в `NumberRow` |
| Сохранение и восстановление в модели | `QSettings`, `initialize`, `_save`; форма не работает с хранилищем |
| Атомарное изменение | `_apply_values` сначала присваивает все три значения |
| Одно уведомление на изменение | Один `changed.emit` после полного изменения |
| Нет уведомления при неизменившихся значениях | Сравнение нового и старого кортежей |
| Один сигнал и одно обновление при запуске | Подключение формы перед `initialize`, защита от повторной инициализации |
| Счётчик обновлений | `MainWindow.update_count`, подпись и консольный вывод |
| Нет утечки диапазона во форму | Границы элементов берутся из `model.minimum` и `model.maximum` |
| Нет обратного цикла сигналов | `QSignalBlocker` при обновлении виджетов |
| Некорректный ввод и уход фокуса | Валидаторы Qt, `focusOutEvent` текстового поля, обработчики подтверждения |
| Работа без формы | Проверка отдельным процессом с `QCoreApplication` и временным хранилищем |

`QSettings` преобразует свой файловый/системный формат в целые значения при чтении.
Это обработка формата хранения; текст из элементов управления модель не получает.
Для B выбран разрешённый методичкой вариант с ограничением до ближайшего значения.
