## Как запустить

В исходной рабочей папке компилятор уже настроен: дважды нажми `run.bat`.
Скрипт сначала использует переносной компилятор из `../tools/zig`, иначе ищет g++ или cl.
Он собирает программу и оставляет окно с выводом открытым.
`build.bat` только собирает программу, `demo.bat` запускает готовую сборку.

Если ты распаковал небольшой архив отдельно, готовая программа уже есть:
дважды нажми `demo.bat`. Для применения изменений исходников понадобится
компилятор и запуск `run.bat`: demo.bat не пересобирает код.

## Другие способы сборки

Вариант с Visual Studio:

1. Нужен компонент «Разработка классических приложений на C++».
2. Создай проект C++ «Пустой проект» / Empty Project.
3. Добавь существующие файлы `main.cpp`, `objects.cpp`, `objects.h`.
4. Запусти без отладки: `Ctrl+F5`.

VS Code — редактор; расширение C/C++ само по себе не устанавливает компилятор.

В терминале с g++:

```powershell
g++ -std=c++11 -Wall -Wextra -pedantic objects.cpp main.cpp -o lab2.exe
.\lab2.exe
```

## Как читать вывод

В программе пять блоков: точка и указатели; наследник без своих конструкторов;
наследник со своими конструкторами; композиция по значению; композиция с указателем.
`Point()` означает конструктор без параметров; `Point(copy)` — конструктор копирования;
`~Point` — деструктор. Английские сообщения оставлены для одинакового вывода в разных консолях.

Сначала разберём только `PointDemo()` и класс `Point`. Следующая тема — указатели,
после неё наследование, затем композиция и владение памятью.
